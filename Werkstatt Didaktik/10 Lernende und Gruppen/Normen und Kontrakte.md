## Kurz

Schriftliche Lernkontrakte zwischen Lernenden und Lehrperson beugen der Konsumhaltung vor und fördern Selbststeuerung. Verhandelt wird nur Verhandelbares, mit Konsequenzen bei Nichteinhalten; weniger Regeln sind mehr.

## Formen

- individuelle Lernplanung: Was will ich erreichen, mit welchen Schritten, mit wem, wann Beratung?
- Kontrakt in einer Lerngruppe: Zusammenarbeit, Aufgabenteilung, Umgang mit Konflikten
- Kontrakt Lehrperson und Klasse: Regeln (Vertraulichkeit, Absenzen, Handy, Pünktlichkeit), Rollen, Ziele, Rückmeldeverfahren

Oft besser als ein Regelkatalog ist eine Kultur des Eingreifens und Offenlegens.

## Vorlage: Kontraktblatt in drei Formen

Lehren kompakt 1 nennt für drei Kontraktformen die Punkte, die im Blatt stehen sollen (S. 201–202). Daraus lässt sich je Form ein Blatt zum Ausfüllen bauen. Für alle gilt: Der Kontrakt wird schriftlich festgehalten, auf Flipchart oder für alle kopiert, und wo möglich von den Beteiligten unterzeichnet (S. 201). Verhandelt wird nur, was verhandelbar ist. Stehen verbindliche Regeln im Blatt, gehören auch die Konsequenzen bei Nichteinhalten hinein (S. 201).

**Blatt A: Individuelle Lernplanung** (Lernende mit sich selbst oder mit einer Lernpartnerin, S. 201)

| Feld | Eintrag |
|---|---|
| Ziele und Teilziele: Was will ich erreichen? | |
| Schritte und Teilschritte: Mit welchen Aktivitäten? | |
| Zusammenarbeit: Mit wem? | |
| Mittel: Was brauche ich? | |
| Kontakte: Welche können mir helfen? | |
| Beratung: Wann suche ich die Beraterin oder den Berater auf? | |
| Beurteilung: Wie beurteile ich meine Ergebnisse? | |

**Blatt B: Kontrakt in einer Lerngruppe** (Lernende untereinander, für ein gemeinsames Projekt, S. 202)

| Feld | Eintrag |
|---|---|
| Zusammenarbeit: Welche Regeln gelten für das geplante Projekt? | |
| Aufgabenteilung: Wer macht was? | |
| Uneinigkeit: Wie gehen wir mit Konflikten um? | |
| Vorgehen: Wie gehen wir vor? | |

**Blatt C: Kontrakt Lehrperson und Klasse** (S. 202)

| Feld | Eintrag |
|---|---|
| Regeln (genannt werden Vertraulichkeit, Absenzen, Handy, Höflichkeit, Toleranz, Pünktlichkeit) | |
| Rolle der Lehrperson | |
| Rolle der Lernenden | |
| Spezielle Aufgaben (zum Beispiel Klassensprecherin, Zimmerchef) | |
| Lerninteressen der Lernenden | |
| Kurz- und mittelfristige Lernziele | |
| Lerninhalte und Lernaufgaben | |
| Vermittlungs- und Aneignungsformen: Aktivitäten, Zusammenarbeit, Gestaltung des Unterrichts | |
| Rückmeldeverfahren (Lernfortschritts- oder Lernproduktkontrolle) | |
| Sonstiges (Sprechstunden, Infrastruktur, Ressourcennutzung) | |

**Fuss des Blatts:** Konsequenzen bei Nichteinhalten (nur bei verbindlichen Regeln) und Unterschriften der Beteiligten, wo möglich. Für Lernungewohnte nennt das Buch als hilfreichere Sanktionen als Ausschluss und Geldbusse unter anderem ein persönliches Gespräch mit einer Vereinbarung von Massnahmen, die Mithilfe bei der Kursdurchführung, eine Aufgabe mit zusätzlichem Lerngewinn und den Auftrag zur schriftlichen Reflexion des Vorgefallenen mit vorgegebenen Fragen (S. 134).

**Kurzform für Lernungewohnte** (S. 135): ein Lernkontrakt, der nur drei Fragen klärt: Wie verhalten wir uns hier? Welche Umgangsformen sollen gelten? Wer achtet darauf, dass die Vereinbarungen eingehalten werden?

**Pflege:** Meyer nennt als schriftliche Form den förmlichen Vertrag, der festlegt, wer was wann zu leisten hat (S. 82). Arbeitsbündnisse müssen gepflegt werden (S. 82).
